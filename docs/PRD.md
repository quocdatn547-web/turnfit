# 家具试搬 TurnFit · 产品需求

状态：已实现并通过验收。更新日期 2026-11-18。

## 使用场景

用户在家具页面看中两款沙发。两款都比门窄，但屋内有一个直角走廊。用户量了两段墙的净宽和拐角前后的可用直线长度，想在下单前知道哪一款在水平搬运时有可行路径。场景包含两款家具，共用同一条走廊。

## 用户流程

1. 打开网页，可直接使用样例或编辑走廊净宽和直段长度，再输入 A、B 两件家具的外接长宽。
2. 点击「对比试搬」，在对应于同一走廊的两张俯视图中，看到各自的求解结果。
3. 有路线的家具可播放，也可拖进度查看每一个中间姿态。显示沿该路线的保守最小净距。
4. 用鼠标、触屏或键盘平移和旋转家具。发生碰撞或违反预留净距时，家具停在此前有效姿态，红色轮廓和对应墙面显示未通过的试探位。
5. 修改尺寸后，结果随输入失效。再次计算才显示新结果。可恢复内置样例。

## 功能边界

- 尺寸使用厘米。每一段走廊在相应方向上以固定净宽围成直角。家具取水平外接矩形。
- 保留净距默认 2 cm，可调整。墙面包括直段的起止边界。
- 路线是模型内的几何可行结果。离散搜索未发现路线时显示「未找到路线」，可改尺寸和净距重试。不考虑竖立、倾斜、可拆卸部件、地面高差和人站位。
- 浏览器本地计算。项目无账号、网络数据或运行时依赖。交付可双击打开的单文件版本。

## 验收

| 编号 | 验收行为 | 验证 |
| --- | --- | --- |
| P1 | A 和 B 同用 104 × 111 cm 的走廊净宽。226 × 88 cm 的 A 未找到路线，148 × 58 cm 的 B 有路线 | UI 演示 + 规划器测试 |
| P2 | B 的路线两端都在正确的直段内，路径上所有插值动作满足净距。改变家具 A 尺寸后能算出不同结果 | 连续段验证 + 独立分段抽样 + UI 修改重算 |
| P3 | 两个视图以同样比例显示家具和墙。拖动或旋转时不能穿墙，失败显示墙面和试探位置；键盘可平移和旋转 | 浏览器鼠标与键盘端到端 |
| P4 | 播放、暂停和拖进度的姿态对应真实路径；改变任一布局参数后，旧路线不可播放 | 浏览器端到端 |
| P5 | 窄屏可操作，文件断网打开即可完整运行。错误输入有明确提示 | 浏览器移动宽度、无网络、输入校验 |
