# TurnFit 验收记录

2026-11-18。验收对象为 `node build.mjs` 生成的 `dist/index.html`。

| 需求 | 验收结果 |
| --- | --- |
| P1 同一走廊两件家具 | 默认样例用 104/111 cm 净宽及 330/315 cm 直段。浏览器显示 226 × 88 cm 未找到路线、148 × 58 cm 找到路线。 |
| P2 连续路径与重算 | `node --test tests/geometry.test.cjs` 五项通过。使用独立线段算法逐段抽查输出净距，并验证端点安全但中间穿过内墙的反例。A 改成 142 × 55 cm 后通过，B 仍通过。 |
| P3 真实尺度、手动操作和碰撞 | 俯视图共享尺寸与比例。浏览器验证鼠标拖动、方向键移动和旋转按键。试搬到墙面时保留上一姿态并画出红色试探位。390 px 视口验证实际触屏事件。 |
| P4 播放状态 | 验证播放、暂停、跳至终点、拖进度及尺寸更新后旧路线禁用。 |
| P5 离线、响应式和错误输入 | Chrome 和 Edge 从本地文件离线打开并自动计算，播放过程中没有外部 HTTP 请求。390 px 下无水平溢出。无效净宽有明确范围提示；恢复示例可回到默认结果。 |
